### **Langkah 1: Persiapan Lingkungan Pengembangan**

Sebelum kita mulai menulis kode untuk aplikasi Anda, pastikan Anda memiliki semua alat dan perangkat lunak yang diperlukan untuk mengembangkan aplikasi.

#### a. **Instalasi Node.js**

Node.js adalah runtime JavaScript di server, dan Anda akan menggunakannya untuk menjalankan backend aplikasi Anda. Anda juga membutuhkan **npm** (Node Package Manager) untuk mengelola dependensi proyek.

* Unduh dan instal **Node.js** dari situs resmi: [https://nodejs.org/](https://nodejs.org/).
* Setelah instalasi selesai, buka terminal atau command prompt dan jalankan perintah ini untuk memverifikasi instalasi Node.js:

  ```bash
  node -v
  npm -v
  ```

  Ini akan menampilkan versi Node.js dan npm yang terinstal.

#### b. **Instalasi MySQL**

MySQL adalah sistem manajemen database yang akan Anda gunakan untuk menyimpan data aplikasi Anda.

* Unduh dan instal **MySQL** dari situs resmi: [https://dev.mysql.com/downloads/installer/](https://dev.mysql.com/downloads/installer/).
* Setelah menginstal MySQL, jalankan MySQL Server dan pastikan Anda dapat mengakses **MySQL Command Line Client** dengan menggunakan username dan password yang Anda buat selama instalasi.

#### c. **Instalasi Vue CLI (untuk Frontend)**

Vue CLI adalah alat untuk membuat dan mengelola proyek Vue.js.

* Instal **Vue CLI** secara global dengan perintah:

  ```bash
  npm install -g @vue/cli
  ```
* Setelah instalasi selesai, Anda dapat memverifikasi instalasi Vue CLI dengan perintah:

  ```bash
  vue --version
  ```

---

### **Langkah 2: Membuat Struktur Proyek**

Sekarang kita akan mulai dengan membuat struktur proyek untuk aplikasi perangkat lunak pusat data Anda.

#### a. **Membuat Folder Proyek dan Inisialisasi dengan npm**

Buat folder baru untuk proyek Anda dan inisialisasi proyek dengan npm:

```bash
mkdir data-center-app
cd data-center-app
npm init -y
```

Perintah ini akan membuat file **`package.json`** yang berisi informasi dasar tentang proyek Anda.

#### b. **Membuat Backend dengan Node.js dan Express.js**

1. **Instalasi Express.js**:
   Express.js adalah framework minimalis untuk Node.js yang akan membantu Anda membangun server backend.

   Install Express.js dengan perintah:

   ```bash
   npm install express
   ```

2. **Membuat File Server**:
   Di dalam folder proyek Anda, buat file baru bernama **`server.js`**. Ini adalah file utama yang akan menjalankan server backend.

   Isi file **`server.js`** dengan kode berikut:

   ```js
   const express = require('express');
   const app = express();
   const port = 3000;

   app.get('/', (req, res) => {
     res.send('Hello, Data Center!');
   });

   app.listen(port, () => {
     console.log(`Server running at http://localhost:${port}`);
   });
   ```

3. **Menjalankan Server**:
   Jalankan server dengan perintah berikut:

   ```bash
   node server.js
   ```

   Jika berhasil, buka browser dan akses `http://localhost:3000`. Anda akan melihat teks "Hello, Data Center!" yang berarti server sudah berjalan dengan baik.

---

### **Langkah 3: Membuat Frontend dengan Vue.js**

1. **Membuat Proyek Vue.js Baru**:
   Di dalam folder proyek Anda, buat aplikasi Vue.js baru dengan menggunakan Vue CLI:

   ```bash
   vue create frontend
   ```

   Ikuti petunjuk di terminal untuk memilih preset yang Anda inginkan (Anda bisa memilih preset default).

2. **Menjalankan Aplikasi Vue.js**:
   Setelah aplikasi Vue.js selesai dibuat, masuk ke direktori **frontend** dan jalankan server pengembangan:

   ```bash
   cd frontend
   npm run serve
   ```

   Aplikasi Vue.js sekarang dapat diakses di **`http://localhost:8080`**.

---

### **Langkah 4: Menghubungkan Backend (Node.js dengan Express) ke MySQL**

Sekarang, kita akan menghubungkan aplikasi backend (Node.js dengan Express) ke MySQL.

1. **Instalasi MySQL Driver untuk Node.js**:
   Install paket `mysql2` untuk menghubungkan aplikasi Node.js Anda ke MySQL:

   ```bash
   npm install mysql2
   ```

2. **Mengonfigurasi Koneksi MySQL di `server.js`**:
   Perbarui file **`server.js`** untuk mengonfigurasi koneksi ke database MySQL. Berikut adalah contoh kode untuk menghubungkan ke database MySQL:

   ```js
   const express = require('express');
   const mysql = require('mysql2');
   const app = express();
   const port = 3000;

   // Membuat koneksi ke database MySQL
   const db = mysql.createConnection({
     host: 'localhost',
     user: 'root', // Ganti dengan username MySQL Anda
     password: '', // Ganti dengan password MySQL Anda
     database: 'data_center_db' // Nama database Anda
   });

   // Koneksi ke database
   db.connect((err) => {
     if (err) {
       console.error('Error connecting to MySQL:', err.stack);
       return;
     }
     console.log('Connected to MySQL as id ' + db.threadId);
   });

   app.get('/', (req, res) => {
     res.send('Hello, Data Center!');
   });

   app.listen(port, () => {
     console.log(`Server running at http://localhost:${port}`);
   });
   ```

3. **Menyiapkan Database di MySQL**:
   Sebelum menjalankan aplikasi, pastikan Anda membuat database **`data_center_db`** di MySQL dengan perintah berikut:

   ```sql
   CREATE DATABASE data_center_db;
   ```
